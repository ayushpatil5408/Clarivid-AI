Context & Background

The Evolution of AI in Education

Why traditional AI video generators fail as effective cognitive learning tools

02 / 12
⚠️ Current Paradigm: Content-Production Tools

Platforms like InVideo, HeyGen, and YouTube AI synthesizers treat video as a rendered, static MP4 file.

  • ✕ Passive Learning: Students watch linearly without active participation.
  • ✕ Heavy & Costly: Video rendering takes minutes and cannot be modified dynamically.
  • ✕ Zero Feedback Loop: The video has no way of checking if the student understood.
💡 The ClariVid Paradigm: Cognitive Micro-Lessons

ClariVid generates structured JSON storyboards paired with in-browser speech synthesis.

  • ✓ Instant Latency: Generates interactive lessons in seconds, not minutes.
  • ✓ Granular Interactivity: Pausing, branching, and live re-explanation.
  • ✓ Dual-LLM Safeguard: Real-time factual auditing before student consumption.
Core Academic Objective:
To engineer a transparent, verifiable prompt-driven system that turns any study topic into an adaptive, fact-checked micro-lecture specifically tuned for college students.

Core Syllabus Focus

5 Key Prompt Engineering Techniques

Direct mapping of theoretical prompt patterns to production implementations

06 / 12
Technique Engineering Pattern Implementation in ClariVid Output Impact
1. Zero-Shot Baseline Standard task instruction with zero examples or explicit persona. `server/prompts/promptA.js` (`buildPromptA`) Serves as comparative baseline; high variance in JSON compliance.
2. Role + Few-Shot + Schema Persona ("Experienced Professor") + 1 complete example + strict schema rules. `server/prompts/promptB.js` (`buildPromptB`) 100% schema adherence, exact 5–7 scenes, ≤120 word narration, exam tags.
3. Critic / Self-Verification Adversarial auditor persona inspecting another LLM's factual accuracy. `server/prompts/criticPrompt.js` (`/audit`) Generates 0–100 confidence score, categorizes issues, outputs corrections.
4. Adaptive Re-Prompting Dynamic context rewriting triggered by user comprehension failure. `server/prompts/reexplainPrompt.js` (`/reexplain`) Rewrites upcoming scene with simplified analogies when student fails quiz.
5. Validation with Retry Output verification loop catching structural faults with reinforcement. `server/services/validator.js` (`callWithRetry`) Guarantees robust JSON parsing before presenting data to student.
Innovation Highlight

The Critic Agent: Dual-LLM Verification

Preventing educational hallucinations before they reach the learner

07 / 12
🛡️ How the Critic Agent Operates
  • 1 Independent Inspection: Receives the complete storyboard from LLM 1 without prompt bias.
  • 2 Rigorous Persona: Instructed as an unsparing academic peer-reviewer looking for subtle flaws.
  • 3 Quantitative Scoring: Scores factual confidence from 0 to 100. Any scene with a flaw is penalized below 70.
  • 4 Actionable Fix: Provides an exact corrected text string to patch the scene instantly.
📊 Live Confidence Visualizer
● HIGH CONFIDENCE (90–100/100)
Mathematically & factually sound. Verified definition.
▲ MODERATE CONFIDENCE (70–89/100)
Minor ambiguity or missing boundary conditions.
✕ LOW CONFIDENCE (<70/100) — ISSUE FLAGGED
Contains factual inaccuracy. One-click "Apply Fix" button active.
Cognitive Interactivity

Adaptive Feedback & Re-Explanation Loop

Transforming passive viewers into actively evaluated learners

08 / 12
🎯 In-Situ Checkpoint Quizzes

Every scene includes a single 4-option multiple choice question assessing the core mental model introduced in that scene.

Example Checkpoint (Tokenization):
"What is the primary unit of text processed by an LLM?"
A) Entire sentences B) Subword tokens ✓ C) Pixels D) Machine bytecode
🔄 Confusion-Triggered Branching
  • ✓ If Correct: Positive reinforcement audio chime, student progresses seamlessly to the next concept.
  • ! If Incorrect: The system automatically captures the misconception, calls `/reexplain`, and the empathetic tutor prompt simplifies the upcoming scene.
  • ★ Outcome: No student is left behind due to misunderstood prerequisites.
